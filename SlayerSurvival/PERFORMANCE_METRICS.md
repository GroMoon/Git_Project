- **5시간/주간 한도 %** : Claude Code 데스크톱의 사용량 조회 기능(`get_usage`, 앱 사용량 카드와 같은 값)으로 17:22, 17:44에 조회했습니다.
  1차 창은 당시 조회하지 않았습니다. 창 전체 사용률은 14:10에 받은 "사용량 거의 임박, 97%까지만 사용" 메시지를 근거로 **약 97%로 추정**했습니다.
- **1차 창의 이 작업 몫** : 5시간 창은 첫 메시지가 있는 시각의 정각부터 5시간입니다(2차 창이 17:00 시작 → 21:59 초기화로 확인).
  따라서 1차 창은 11:00~15:59이고, 그 안에 **다른 세션 2개**가 함께 있었습니다(아래 3장 표). 로컬 기록의 토큰 비중으로
  이 작업 몫을 나눠 **97% × 46~56% ≈ 45~54% (약 50%)**로 추정했습니다. 토큰 종류별 한도 가중치가 공개되어 있지 않아 범위로 적었습니다.
- **토큰** : 로컬 세션 기록 파일(`~/.claude/projects/C--Users-MoonS-Desktop-git-project-SlayerSurvival/9ba5a258-41cb-4738-8c93-489a913900b4.jsonl`)에 남은 API 응답별 사용량을 메시지 ID 기준으로 중복 없이 합산했습니다.
- **시간** : 같은 기록 파일의 타임스탬프 기준입니다. 작업 시간은 프롬프트를 받은 시각부터 그 프롬프트에 대한 마지막 응답 시각까지로 계산했습니다.

- 고블린 돌진 베기가 사거리 밖에서 시작돼 항상 빗나가던 문제 → 사거리·돌진 거리 조정
- 일시정지 메뉴를 닫는 ESC가 메뉴를 다시 여는 문제 → 이벤트 방식 입력으로 전환
- 마법사 마력탄이 띄운 적을 지나쳐 버리던 문제 → 높이 판정 확대
